## The Mission

Two paths exist for AI and technology.

**Path One:** AI becomes a tool of restriction. Big companies build walls.
Access costs money. Technical knowledge is the price of admission.
The people who already have power get more. Everyone else gets left behind.

**Path Two:** AI becomes infrastructure. Free to access, powerful in
everyone's hands, impossible to wall off because it lives on your own machine.

FreedomForge AI is Path Two.

## 🔲 Phase 9 — Plugin Ecosystem (The Big One)

This is where FreedomForge AI becomes something no one has built before.

**The idea:** Instead of a marketplace where developers post plugins for users
to download, FreedomForge AI helps each user BUILD their own plugin for their
specific need. That plugin then gets contributed anonymously to a shared repo.
Future users with similar needs get the AI to look at what already exists,
use it as a foundation, and improve it for their specific situation.
The improved version goes back into the repo.

The repo grows smarter over time. Each plugin makes the next one faster to build.
The community isn't manually coding things one by one — they're describing what
they need and the system builds it, tests it, and shares it automatically.

No personal data ever leaves. No profiles. Just code.

**The result:** Within a year, the plugin library covers things no single team
could ever build — because it's not people building one by one, it's thousands
of people's needs being translated into code simultaneously, each one making
the next easier.

**Safety:** All plugin building happens inside a sandboxed VM.
Plugins are tested there before they ever touch the real system.
One click pulls a working plugin out of the sandbox and installs it.
If it breaks anything in the VM, the real computer is completely untouched.

## 🔲 Phase 10 — Integrity & Sovereignty

This is the foundation that makes everything else trustworthy forever.

- **Immutable plugin ledger** — blockchain-style verification so plugins
  can't be silently modified. Community owns the integrity, not any company.
- **SHA integrity checking** — app verifies its own files on launch.
  If anything has been tampered with, it alerts the user immediately.
- **Automated restore points** — every 4/8/12 hours (user configurable),
  creates a full system restore point with SHA verification.
  If integrity check fails, offers to restore to last known good state.
  User always decides — never automatic.
- **Idle AI learning** — when the computer is idle, AI can optionally
  run simulations, test the programs it's created, and if improvements
  are found, create a notification for the user to review and optionally
  save the improved version. All testing in VM sandbox.
